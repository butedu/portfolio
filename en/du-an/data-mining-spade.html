SPADE

Overview.

This app demonstrates SPADE on transaction data to find sequences of items commonly bought across multiple purchases.

Features.

  1. Prepare data

    Import transactions from CSV and clean up missing or duplicate records.

  2. Mine sequential patterns

    Run SPADE with a user-selected support threshold. The app lists each pattern and its support.

  3. Review results

    View charts, transaction statistics and product suggestions based on the sequences found.

Technologies.

  • Python
  • Pandas
  • Tkinter
  • Matplotlib
