RFID Attendance.

An RFID simulation that reads cards, signals access status and records attendance in Google Sheets.

Source code on GitHub

Overview.

The Wokwi model simulates RFID attendance. The ESP32 checks each card ID and responds at the device.

Features.

  1. Read and verify cards

    Check each card ID against the simulation's list of valid cards.

  2. Device feedback

    LEDs, a buzzer and a relay indicate whether access is granted or denied.

  3. Save attendance records

    The ESP32 sends JSON to Google Apps Script to record attendance in Google Sheets.

Technologies.

  • ESP32
  • RFID RC522
  • Wokwi
  • Google Sheets
