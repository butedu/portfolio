Online Certificate
Classroom.

An online certificate classroom connecting learners, teachers and administrators.

Source code on GitHub

Overview.

A full-stack project for managing certificate courses, from enrollment and assessments to results. Learners, teachers and administrators each have their own areas and permissions.

Features.

  1. Learners

    Browse courses and lessons, track progress, take mini-tests, join discussions and view results or certificates.

  2. Teachers and administrators

    Manage chapters, lessons, assessments and grading. Administrators manage the course catalogue, users, orders and promotions.

  3. Payments and authentication

    Integrates VNPay, Google sign-in, OTP password recovery and role-based permissions.

  4. Web and mobile

    A Laravel Sanctum REST API shares data and workflows with the Flutter application.

Technologies.

  • Laravel 11
  • PHP 8.2
  • MySQL 8
  • Blade
  • Sanctum
  • Flutter API
  • VNPay
