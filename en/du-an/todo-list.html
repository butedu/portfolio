MY TASKS

Overview.

A personal task manager developed with Flutter and Firebase, built to organize priorities and track everyday progress.

Features.

  1. Accounts

    User registration and sign-in with Firebase Authentication.

  2. Real-time tasks

    Create, update and delete tasks with Cloud Firestore synchronization.

  3. Progress and priorities

    Mark tasks as complete, set priorities and review progress statistics.

Technologies.

  • Flutter
  • Dart
  • Firebase Authentication
  • Cloud Firestore
